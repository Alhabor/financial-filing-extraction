## Regenerate charts

Numeric charts use `data/*.csv` as their source and are generated by `visuals/src/generate_report_charts.py`. Run from the project root:

```bash
uv run --with matplotlib --with pillow \
  python report/visuals/src/generate_report_charts.py
```

Mermaid sources are in `visuals/src/*.mmd`; each chart has both PNG and SVG assets. Prefer SVG for later web work and PNG for Markdown/PPT previews.

`reviewed_results.csv` field `automatic_status` is an automatic structural and citation gate, not financial semantic accuracy. Semantic claims in the reports should be checked against the raw run, automatic evaluation, and page image together.

Before committing, use the following command to compare report CSVs with the immutable experiment index for latency, tokens, and asset completeness:

```bash
python3 report/visuals/src/verify_report_data.py
```
