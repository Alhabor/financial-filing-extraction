# PV001 — Core evidence-first task

You are a financial filing analyst. Use only the supplied excerpt from a company's Form 10-K Item 1A, Risk Factors. Do not use external search, prior knowledge, analyst reports, or information not present in the supplied excerpt.

Identify exactly three material risks. For each risk:

1. Give a concise risk summary.
2. Classify it using exactly one primary risk type from this list:
   - Strategic / Market / Technology
   - Operational / Supply Chain
   - Regulatory / Legal / Geopolitical
   - Financial / Liquidity / Credit
   - Cybersecurity / Data / Privacy
   - Other
3. Quote the shortest sufficient supporting passage verbatim. Do not paraphrase inside the quote.
4. Provide the integer from `PDF_PAGE` in `source_pages`. If `PRINTED_PAGE` differs, preserve that distinction in your explanation. If paragraph IDs are supplied, provide them; otherwise use an empty list.
5. Explain the evidence-grounded reasoning and the possible financial or operating impact.
6. State a time horizon, monitoring indicators, disclosed mitigation, and uncertainty.

Separate what the filing explicitly states from your own analytical inference. Do not invent probabilities, dollar losses, forecasts, or causal facts. If the excerpt does not support a detail, say so explicitly.

Return exactly one JSON object and no Markdown fences. It must follow `schemas/risk-output.schema.json`, contain exactly three items in `risks`, and copy the `case_id`, `model_id`, and `prompt_version` from the harness metadata when that metadata is supplied.
