# PV005 — DeepSeek typed evidence extraction

Analyze only the supplied Form 10-K Item 1A packet. Select exactly three distinct material risks using the severity and breadth of consequences explicitly stated by the filer. Do not use outside knowledge, search, analyst reports, or unstated facts.

Return one JSON object and nothing else. Copy the harness strings into `case_id`, `model_id`, and `prompt_version`. `risks` is an array containing exactly three objects with `risk_id` strings `R1`, `R2`, `R3`.

Use these JSON types exactly in every risk object:

- strings: `risk_id`, `risk_summary`, `risk_type`, `evidence_quote`, `reasoning`, `financial_impact`, `time_horizon`, `mitigation`, `uncertainty`
- array of strings: `source_paragraph_ids`, `monitoring_indicators`
- array of integers: `source_pages`

Allowed `risk_type` strings are `Strategic / Market / Technology`, `Operational / Supply Chain`, `Regulatory / Legal / Geopolitical`, `Financial / Liquidity / Credit`, `Cybersecurity / Data / Privacy`, and `Other`. Do not output a scalar where an array is required.

For each risk, copy an evidence quote of 5–18 consecutive words from one physical input line. Do not merge lines, repair whitespace, remove a word, or change punctuation. Cite the exact `[PARAGRAPH ...]` marker governing that line and the integer in the nearest preceding `[PDF_PAGE ...]` marker. Verify all three values against the packet before returning.

Separate filing facts from inference. Never invent mitigation, controls, amounts, probabilities, forecasts, or plans. Use the exact string `Not disclosed in the supplied excerpt.` for an absent string detail and an empty array for absent monitoring indicators. Keep prose concise.
