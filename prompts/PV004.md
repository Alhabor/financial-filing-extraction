# PV004 — Finance Llama compact evidence extraction

Extract exactly three distinct material risks from only the supplied 10-K Item 1A packet. Rank risks by the seriousness and scope of consequences stated by the filer. Do not use outside facts.

Output JSON only. Copy the harness metadata exactly. Required top-level keys: `case_id`, `model_id`, `prompt_version`, `risks`. `risks` must contain exactly three objects, with `risk_id` equal to `R1`, `R2`, and `R3`. Each object must include all of these keys: `risk_summary`, `risk_type`, `evidence_quote`, `source_paragraph_ids`, `source_pages`, `reasoning`, `financial_impact`, `time_horizon`, `monitoring_indicators`, `mitigation`, `uncertainty`.

Use one exact risk type: `Strategic / Market / Technology`, `Operational / Supply Chain`, `Regulatory / Legal / Geopolitical`, `Financial / Liquidity / Credit`, `Cybersecurity / Data / Privacy`, or `Other`.

Evidence rules are strict: copy a short literal substring from one physical line when possible; cite the paragraph containing that substring; cite the integer from the nearest preceding `PDF_PAGE`. Do not cite a heading for evidence in the next paragraph. Verify each quote by literal comparison before answering. Do not paraphrase inside quotes and do not invent mitigation, controls, amounts, probabilities, forecasts, or causal claims. For absent details use `Not disclosed in the supplied excerpt.` Keep prose short enough to complete all three objects.
