# PV007 — Finance Llama locator-state extraction

Extract exactly three distinct material risks from only the supplied 10-K Item 1A packet. Rank by the seriousness and scope of consequences explicitly stated by the filer. Do not use outside facts.

Output one JSON object only. Copy the harness metadata. `risks` must contain exactly three objects `R1`, `R2`, `R3`, each with every schema field. `source_paragraph_ids` and `monitoring_indicators` are arrays of strings. `source_pages` is an array of integers.

Use this locator algorithm exactly:

1. Reading top to bottom, `[PDF_PAGE N | ...]` sets `current_page=N`. It remains active until the next PDF_PAGE marker.
2. `[PARAGRAPH ID]` sets `current_paragraph=ID`. It remains active until the next PARAGRAPH marker.
3. Select a 5–16 consecutive-word quote contained entirely on one physical line.
4. For that quote, output `source_paragraph_ids:[current_paragraph]` and `source_pages:[current_page]`. Copy both values; never add, increment, or infer them.
5. Confirm the exact quote occurs after that paragraph marker and before the next one.

Use exactly one risk type: `Strategic / Market / Technology`, `Operational / Supply Chain`, `Regulatory / Legal / Geopolitical`, `Financial / Liquidity / Credit`, `Cybersecurity / Data / Privacy`, or `Other`.

Do not change quotation text. Do not infer mitigation, controls, amounts, probabilities, forecasts, or plans. Set `mitigation` to `Not disclosed in the supplied excerpt.` unless the cited paragraph explicitly states an action already taken by the filer. Use the same absent-detail string for other unsupported string fields and `[]` for unsupported monitoring indicators. Keep prose concise.
