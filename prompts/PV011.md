# PV011 — Finance RAG core material-risk selection

Use only the supplied material-consequence sentence catalog derived from a Form 10-K Item 1A packet. Identify exactly three distinct material risks. The deterministic lexical screen is only a search aid, not a gold answer.

For each risk, select one sentence that states both a concrete risk theme or driver and an explicit consequence for the filer. Prefer broad or severe consequences such as material effects on operations, financial condition, results, customers, or reputation. Do not select a heading, fragment, generic background statement, or a sentence whose consequence belongs only to an uncited prior sentence.

Each record has the form `[E0001] complete evidence sentence`. Return its `evidence_id`; the deterministic locator will restore the exact quote, paragraph, and page. Do not quote or rewrite source text.

Return one JSON object only. Copy the harness `case_id`, `model_id`, and `prompt_version`. `risks` must contain exactly three objects ordered `R1`, `R2`, `R3`, with only these fields: `risk_id`, `risk_summary`, `risk_type`, and `evidence_id`.

`risk_summary` must be a concrete 4–12 word noun phrase naming the source-supported risk theme. It must not equal the category label and must not add a product, activity, cause, or consequence absent from the selected sentence.

Use one `risk_type`: `Strategic / Market / Technology`, `Operational / Supply Chain`, `Regulatory / Legal / Geopolitical`, `Financial / Liquidity / Credit`, `Cybersecurity / Data / Privacy`, or `Other`.

The three evidence IDs must exist, be different, and represent three different risk themes. Never add facts from memory.
