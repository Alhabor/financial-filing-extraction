# PV008 — Finance RAG evidence selection

Use only the supplied evidence catalog derived from a Form 10-K Item 1A packet. Identify exactly three distinct material risks based on the seriousness and breadth of consequences explicitly stated by the filer.

Each catalog record has the compact form `[E0001] exact physical source line`. Select exactly one consequence-bearing `evidence_id` for each risk. Copy that ID exactly. Do not quote, rewrite, or generate source text; the deterministic locator will retrieve the corresponding frozen line and its archived paragraph/page metadata after your response.

Return one JSON object only. Copy the harness `case_id`, `model_id`, and `prompt_version`. `risks` must contain exactly three objects with `risk_id` values `R1`, `R2`, `R3`. Every risk object must contain:

- string fields: `risk_id`, `risk_summary`, `risk_type`, `evidence_id`, `reasoning`, `financial_impact`, `time_horizon`, `mitigation`, `uncertainty`
- array of strings: `monitoring_indicators`

Use exactly one risk type: `Strategic / Market / Technology`, `Operational / Supply Chain`, `Regulatory / Legal / Geopolitical`, `Financial / Liquidity / Credit`, `Cybersecurity / Data / Privacy`, or `Other`.

Selection checks:

1. The chosen evidence ID must exist verbatim in the supplied catalog.
2. Its following source line must contain at least five words and state a risk cause, consequence, or financial/operating exposure—not merely a heading.
3. Use three different evidence IDs representing three distinct risk themes.
4. Base reasoning and financial impact on the selected source line and nearby catalog context only.

Do not invent controls, amounts, probabilities, forecasts, or plans. For this preparation round set `mitigation` exactly to `Not disclosed in the selected evidence line.` Keep every field concise.
